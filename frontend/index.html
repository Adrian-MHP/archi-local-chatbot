Archi Local Chatbot

Checking MCP Model: --

1. Setup & Context

Define one or more As-Is/To-Be source pairs -- each pair gets its own separate Archi views, never merged with another pair's. Then check the current Archi model for existing views before starting. Mirrors the Setup & Context Agent from the assessment spec.

2. As-Is Capture (Business Process Extractor)

Upload the As-Is process document(s) for each source defined in Setup. Files uploaded into the same source are still chained together (drag to reorder), but sources are never merged with each other -- each becomes its own separate Archi view. Nothing is written to Archi until you review and apply.

3. To-Be Architecture (Target Architecture Builder)

Upload the To-Be process document(s) for each source, or let an agent propose one from that source's As-Is processes. Each source keeps its own separate Archi view, paired with its As-Is source from Setup. Each upload is checked against its paired As-Is processes so an unrelated document gets flagged.

4. Mapping & Gap Analysis

Compares each As-Is business process view against its paired To-Be view and classifies each pairing as a full match, partial match, legacy process with no To-Be equivalent, or a new To-Be process with no As-Is equivalent. Confirm or correct the pairing below before running the analysis. Applying creates a separate mapping view per pair in Archi.

5. Business Summary

Turns the mapping and gap results into a steerco-ready executive summary you can present or hand out as a PDF.
